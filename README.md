# Credit Score Prediction

This project explores predicting individual credit scores using demographic and financial variables.

## Overview

- Data cleaning and preprocessing of various numerical and categorical features
- Exploratory analysis to understand feature distributions and relationships
- Supervised classification models applied to estimate credit score outcomes
- Evaluation of model performance and limitations
